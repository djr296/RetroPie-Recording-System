# Changelog

## 0.1.0 - 2026-09-14

- Capture the composed DispmanX display at 1280×720 and 30 FPS.
- Encode video with Raspberry Pi OpenMAX H.264 acceleration.
- Duplicate HDMI audio into a clean ALSA loopback recording source.
- Start and stop recordings with a learned controller button combination.
- Show recording state through RetroArch's on-screen notifications.
- Name and organize recordings from RetroPie's game-launch metadata.
- Finalize recordings automatically when a game exits.
- Add audio restoration and complete uninstall commands.
